This browser can't write NFC tags

Web NFC needs Chrome on Android over https://. On a desktop, an iPhone, or a plain http:// address the buttons below stay disabled. Two ways round it: write the tags once with the free NFC Tools app (choose Write → Add a record → URL and paste the link from each row), or put this app behind an HTTPS tunnel and come back to this page.

This must be the address guests' phones can reach — your public domain, not localhost. Change it here before writing and every link below updates. Rewritable tags can be re-written later, but you only want to do this once.
