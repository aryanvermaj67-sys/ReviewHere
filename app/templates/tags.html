Writing the physical tags

  1. NTAG213 stickers are the right chip — cheap, rewritable, and far bigger than these links need.
  2. Deploy this app to a real domain first, so the link you burn onto the tag is one a guest's phone can actually open.
  3. Write each link as a URL record: use the Write stickers page from an Android phone, or the NFC Tools app on any phone.
  4. Test by tapping, then lock the tag if you want it read-only — locking is permanent.
  5. The printable QR sheet is the fallback for iPhones with NFC scanning switched off.
